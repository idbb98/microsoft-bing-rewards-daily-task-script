    📝 更新日志¶

    以下版本记录为 浏览器脚本版 的更新历史。其他版本（Python / .NET / 扩展）的更新记录请参阅对应文档页。

    当前版本¶

    最新版本：26.7.16.2

    2026-07-16 发布 · 一键安装：BingRewards.user.js

    版本历史¶

    26.7.16.2 — 2026-07-16¶

    • 功能增强：新增 dashboard 每日活动区域未完成任务自动点击功能，在执行 earn 跳转前先处理 rewards.bing.com/dashboard 页面 #dailyset 区域的未完成任务
    • 错误处理：针对页面元素加载延迟、DOM 结构变化等异常情况增加重试与兜底机制
    • 架构优化：日常任务点击与每日活动任务点击的时序参数合并为统一的 tasks* 参数体系，简化配置
    • 向后兼容：新增旧参数迁移逻辑，自动将 earnTasks* / dashboardTasks* 迁移到 tasks*
    • 配置导入兼容：支持从旧版本导出的配置文件（含 earnTasks* / dashboardTasks* 格式）自动映射到新格式

    26.7.16.1 — 2026-07-14¶

    • 功能增强：新增日常任务自动点击功能，在执行搜索任务前自动点击待完成且有积分的任务
    • 功能增强：搜索打开的标签页自动关闭

    26.7.6.1 — 2026-07-06¶

    • 功能增强：新增每周首次运行提示弹窗

    26.6.18.1 — 2026-06-18¶

    • 功能优化：优化搜索结果链接获取及点击逻辑
    • 默认参数调整：暂停时间范围调整为 20-30 分钟；随机暂停间隔调整为 2-3 次搜索

    26.5.1.1 — 2026-04-29¶

    • 功能增强：新增「点击搜索结果链接」配置选项，默认关闭，用户可在设置页面自行开启
    • 问题修复：解决随机滚动功能不生效的问题
    • 布局优化：全面支持响应式设计，适配不同屏幕尺寸和分辨率

    26.4.13.1 — 2026-04-13¶

    • UI 全面重构：现代化设计语言，渐变图标容器、分层阴影、圆角优化
    • 交互动画增强：展开/收起面板平滑旋转动画，按钮三态反馈（默认/悬停/按下）
    • 布局智能适配：收起模式极致紧凑（200px），展开模式信息完整（380px）
    • 状态栏优化：底部三栏布局（页面状态 | 任务执行 | 版本号）
    • 设置页面升级：三段式布局、卡片式表单、动态勾选标记
    • 图标系统优化：全面采用 Emoji 图标，CSS rotate 实现 180° 平滑翻转
    • 性能提升：CSS 变量主题系统，支持系统级暗色模式自动切换，动画 GPU 加速

    26.2.13.1 — 2026-02-13¶

    • 搜索 URL 优化：调整搜索 URL 参数构建，增强脚本行为真实性
    • 菜单优化：调整菜单顺序，提升用户体验

    26.1.26.1 — 2026-01-26¶

    • 统一搜索配置：移除设备类型区分，采用单一最大搜索次数配置
    • 动态间隔控制：暂停间隔与暂停时间采用区间随机配置，增强行为真实性
    • UI 界面优化：重构状态面板样式
    • 行为模拟优化：实现随机滚动策略，模拟真实用户浏览行为
    • 参数稳定性：启动参数采用每日固定机制
    • 扩展参数池：扩充启动参数标记数组，增强脚本随机性与安全性

    26.1.15.1 — 2026-01-15¶

    • 功能增强：增加随机加词和截词功能（默认关闭）
    • 参数化配置：实现启动参数标记可配置化

    26.1.6.1 — 2026-01-06¶

    • 热词获取优化：增加多源热词接口，完善热词补充与过滤机制
    • 随机算法升级：改进 Fisher-Yates 洗牌算法，提高随机性质量
    • 版本管理：调整版本号格式为年-月-日-版本号格式

    0.0.7 — 2025-12-31¶

    • 问题修复：修正剩余时间计算错误及下个搜索词显示异常

    0.0.6 — 2025-12-24¶

    • 问题修复：解决面板关闭按钮失效问题
    • 功能增强：增加面板显示/隐藏切换功能
    • 交互优化：优化关闭按钮悬停效果
    • 问题修复：修复倒计时变量引用错误

    0.0.5 — 2025-10-31¶

    • UI 优化：改进状态面板 UI 设计
    • 功能增强：添加精确计时器，不受页面可见性影响
    • 逻辑优化：改进搜索词获取策略

    0.0.4 — 2025-10-30¶

    • 功能增强：添加搜索任务暂停机制
    • 显示优化：改进进度显示方式
    • 问题修复：修复移动端搜索数量限制问题

    0.0.3 — 2025-10-30¶

    • 逻辑优化：优化搜索 URL 构建逻辑
    • 参数丰富：添加更多搜索参数变化
    • 错误处理：改进错误处理和重试机制

    0.0.2 — 2025-10-13¶

    • 功能新增：添加状态显示面板
    • 后台支持：支持后台运行和页面活跃状态显示
    • 策略优化：优化搜索词获取策略

    0.0.1 — 2025-08-22¶

    • 功能发布：初始版本发布
    • 设备兼容：支持 PC 和移动端自动搜索
    • 进度追踪：基础进度追踪功能
