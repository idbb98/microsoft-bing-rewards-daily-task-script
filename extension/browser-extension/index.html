    🧩 浏览器扩展版¶

    基于 Manifest V3 的浏览器扩展，支持 PC / 移动端双端搜索，无需安装脚本管理器。

    已停止维护

    该版本已停止维护，不再提供更新。目前推荐使用 浏览器脚本版（如需桌面程序可选 Python 桌面版）。

    基本信息¶

    项目 说明
    技术栈 HTML + CSS + JavaScript (Manifest V3)
    支持浏览器 Microsoft Edge / Google Chrome / 其他 Chromium 内核浏览器
    安装方式 加载已解压的扩展 / 拖拽 CRX 文件
    注入范围 https://*.bing.com/*
    当前状态 ⚠️ 已停止维护

    核心优势

    • 无需脚本管理器：作为原生浏览器扩展运行
    • 双端支持：PC 端与移动端均可使用
    • 沙盒隔离：扩展独立权限模型，数据安全

    ✨ 功能特性¶

    • 自动搜索任务：自动完成 Bing 每日搜索任务
    • 实时进度显示：扩展图标与弹窗内显示任务进度
    • 可视化设置：图形化参数配置界面
    • 双端适配：PC 端与移动端浏览器均支持
    • 任务状态持久化：后台 Service Worker 持续管理任务状态

    🚀 安装方法¶

    方式一：加载已解压的扩展¶

    1. 下载源码：从 Gitee 仓库 下载 bing-rewards-extension 目录
    2. 打开扩展管理页：
    3. Edge：访问 edge://extensions/
    4. Chrome：访问 chrome://extensions/
    5. 开启开发者模式：点击页面右上角「开发者模式」开关
    6. 加载扩展：点击「加载已解压的扩展程序」，选择 bing-rewards-extension 目录

    方式二：拖拽 CRX 文件（旧版本）¶

    1. 下载扩展的 .crx 文件
    2. 打开浏览器扩展管理页并开启「开发者模式」
    3. 将 .crx 文件拖拽到扩展管理页面
    4. 根据浏览器提示确认安装

    新版浏览器限制

    新版 Chrome/Edge 已禁止直接拖拽安装外部 CRX 文件，建议使用「加载已解压的扩展」方式。

    📖 使用说明¶

    1. 打开 Bing 并登录：访问 https://www.bing.com，确保已登录微软账户
    2. 启动任务：点击浏览器工具栏的扩展图标，在弹窗中点击「开始」按钮
    3. 查看进度：扩展弹窗与图标角标实时显示任务进度
    4. 等待完成：任务完成后自动停止，积分自动到账

    🗂️ 项目结构¶

└── README.md               # 说明文档

    ⚙️ 权限说明¶

    扩展请求的权限包括：

    权限 用途
    storage 保存配置与任务状态
    alarms 后台定时任务管理
    activeTab 获取当前标签页信息
    tabs 管理标签页
    https://*.bing.com/* 注入脚本到 Bing 页面

    隐私承诺

    所有配置与状态数据仅存储在浏览器本地，不收集、不上传任何个人信息。

    ❓ 常见问题¶

    1. 扩展加载失败¶

    • 问题：提示「清单文件缺失或不可读取」
    • 解决：确认选择了包含 manifest.json 的正确目录（bing-rewards-extension），而非外层项目目录

    2. 扩展图标不显示¶

    • 问题：工具栏没有出现扩展图标
    • 解决：点击浏览器工具栏的拼图图标，将扩展固定到工具栏

    3. 任务无法启动¶

    • 问题：点击「开始」后没有反应
    • 解决：确认已打开 Bing 页面并登录；刷新 Bing 页面后重试；检查扩展是否被浏览器禁用

    4. 移动端如何使用¶

    • 问题：手机浏览器无法安装扩展
    • 解决：推荐改用 浏览器脚本版（配合 Kiwi Browser 等支持扩展的移动浏览器）
