# 📌 版本历史（浏览器脚本版）

> 仅记录浏览器脚本版（`BingRewards.user.js`）的更新历史。

!!! success "最新版本：`26.10.31.1`"
    2026-10-23 发布 · 一键安装：[BingRewards.user.js](https://gitee.com/idbb98/microsoft-bing-rewards-daily-task-script/raw/master/BingRewards.user.js)

## `26.10.31.1` — 2026-10-23

- **问题修复**：任务点击改为「点击 → 回读校验 → 补点一次」，回读仍有未完成任务时不写完成标记，修复「面板显示完成但日常任务 / 每日活动实际未完成」；任务区域缺失、卡片未渲染或仍为 loading 骨架屏时同样不写完成标记
- **执行优化**：点击任务后标签页停留 6 秒再关闭（`taskTabDwell`），避免秒关导致目标页未上报活动；合成点击被弹窗拦截时改用 `GM_openInTab` 打开任务链接，新增卡片点击间隔参数 `tasksClickDelay`
- **功能新增**：菜单新增「🧹 清除当天任务缓存」，一键清除日常任务 / 每日活动的完成、注入、超时与放弃标记，搜索次数与当日终止标记，APP 签到与阅读进度，并复位内存状态，便于当天重跑
- **功能新增**：设置页新增 APP 设备标识预设（10 款 Android / iOS 机型可选并预览 UA），`channel` / `version` / UA 构建号联动，切换后无需重新授权

## `26.9.30.1` — 2026-09-30

- **架构重构**：APP 端网络请求统一封装为 `request()`，替代原 `appHttpRequest()`，新增 `getAppClient()`、`getAccountProfileUrl()`，提升可读性与复用性
- **任务流状态机**：新增注入标记、未完成连续失败计数与「当日跳过」记录（含原因）机制，新增 `isTaskTerminatedToday()` 统一收敛「当日放弃」判定
- **面板状态**：重写 `updateStatusPanel()`，新增 `derivePanelStatus()`、`resetPanelStatus()`、`buildPanelNotice()`，状态推导更清晰、结构更稳健
- **任务采集**：`collectIncompleteTasks()`/`isIncompleteProgress()` 取代 `findIncompleteTaskCards()`/`findIncompleteDashboardTasks()`，统一 earn 与 dashboard 未完成任务采集逻辑
- **清理**：下线 `migrateOldTaskParams()` 旧参数迁移逻辑（早期 `earnTasks*`/`dashboardTasks*` 参数已停用）

## `26.8.31.6` — 2026-08-28

- **功能新增**：新增 APP 端每日签到、资讯阅读（上限可配置）与一键授权流程，令牌自动续期
- **功能增强**：展开面板新增任务完成状态与 APP 阅读 X/Y 进度显示，刷新后实时同步
- **执行优化**：任务执行顺序调整为 dashboard → earn → APP 签到 → APP 阅读 + 搜索，已完成任务当日自动跳过
- **问题修复**：修复重试预算误耗、阅读进度计数漂移、进度正则误判日期、旧浏览器 CSS 兼容性等问题

## `26.8.27.1` — 2026-08-27

- **功能增强**：设置页新增「自动点击任务」总开关，一键控制 earn 日常任务 与 dashboard 每日活动区域未完成任务的自动点击；关闭后上述自动点击将全部不再执行
- **参数调整**：「自动点击任务」总开关默认值调整为关闭，需在设置页手动开启
- **功能调整**：设置页「关于」移除内置更新日志展示，改为在线文档链接（文档首页 / 更新日志）
- **文档同步**：设置页增加提示「任务点击仅支持新版页面」，并同步更新脚本说明文档
- **架构优化**：earn/dashboard 跳转不再使用固定参数 `autoProcess`，改为复用每日生成的启动参数（与搜索参数保持一致），提升行为真实性与一致性
- **参数扩充**：增补 `startParams` 启动参数标记数组数量，扩大每日参数池

## `26.7.16.2` — 2026-07-16

- **功能增强**：新增 dashboard 每日活动区域未完成任务自动点击功能，在执行 earn 跳转前先处理 `rewards.bing.com/dashboard` 页面 `#dailyset` 区域的未完成任务
- **错误处理**：针对页面元素加载延迟、DOM 结构变化等异常情况增加重试与兜底机制
- **架构优化**：日常任务点击与每日活动任务点击的时序参数合并为统一的 `tasks*` 参数体系，简化配置
- **向后兼容**：新增旧参数迁移逻辑，自动将 `earnTasks*` / `dashboardTasks*` 迁移到 `tasks*`
- **配置导入兼容**：支持从旧版本导出的配置文件（含 `earnTasks*` / `dashboardTasks*` 格式）自动映射到新格式

## 版本号说明

版本号格式为 `年.月.日.修订号`（如 `26.7.16.2`），遵循 **YY.M.D.Revision** 规则：

| 部分 | 含义 |
|------|------|
| `26` | 年份（2026） |
| `7` | 月份（7 月） |
| `16` | 日期（16 日） |
| `2` | 当日修订号（当天第 2 次修订） |
