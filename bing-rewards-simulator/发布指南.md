# BingSearchAutomation 发布指南

## 发布脚本使用说明

### 脚本功能

`publish.bat` 是一个自动化发布脚本，提供以下功能：

- ✅ 检查 .NET SDK 环境
- ✅ 清理旧的构建文件
- ✅ 构建 Release 版本
- ✅ 发布应用程序到独立目录
- ✅ 验证发布结果
- ✅ 显示发布文件结构

### 使用方法

#### 方法一：直接双击执行

1. **找到脚本文件**
   - 在项目根目录找到 `publish.bat` 文件

2. **双击执行**
   - 直接双击 `publish.bat` 文件
   - 或右键点击 → 选择 "以管理员身份运行"

#### 方法二：在命令行执行

1. **打开命令行**
   - 按下 `Win+R` 键，输入 `cmd` 打开命令提示符
   - 或输入 `powershell` 打开 PowerShell

2. **进入项目目录**
   ```bash
   cd d:\test\BingSearchAutomation
   ```

3. **执行脚本**
   - 在 cmd 中：`publish.bat`
   - 在 PowerShell 中：`./publish.bat`

### 执行过程

脚本执行时会显示以下步骤：

1. **检查 .NET SDK 版本** - 验证环境是否正确
2. **清理旧的构建文件** - 确保构建环境干净
3. **构建 Release 版本** - 编译优化的发布版本
4. **发布应用程序** - 生成完整的发布包
5. **验证发布结果** - 检查可执行文件是否生成
6. **检查发布文件结构** - 显示所有发布文件

### 发布结果

发布成功后，会在项目根目录生成 `publish/` 目录，包含以下文件：

```
publish/
├── appsettings.json          # 应用配置文件
├── BingSearchAutomation.exe   # 主可执行文件
├── BingSearchAutomation.exe.config  # 应用配置
├── BingSearchAutomation.pdb   # 调试符号文件
├── Newtonsoft.Json.dll        # JSON 处理库
├── NLog.config                # 日志配置文件
├── NLog.dll                   # 日志库
└── WindowsInput.dll           # 键盘输入模拟库
```

## 手动发布步骤

如果需要手动发布，可以按照以下步骤操作：

### 1. 清理项目

```bash
dotnet clean -c Release
```

### 2. 构建 Release 版本

```bash
dotnet build -c Release
```

### 3. 发布应用程序

```bash
dotnet publish -c Release -o publish
```

### 4. 验证发布结果

检查 `publish/` 目录是否包含所有必要文件。

## 发布前准备

在发布前，建议完成以下准备工作：

### 1. 配置应用设置

编辑 `appsettings.json` 文件，根据需要调整配置：

```json
{
  "SearchConfig": {
    "SearchCount": 30,          // 搜索次数
    "SearchInterval": 1000,     // 搜索间隔（毫秒）
    "BrowserPath": "",          // 浏览器路径（可选）
    "SearchUrl": "https://www.bing.com/"  // 搜索URL
  },
  "LogConfig": {
    "LogLevel": "Info",         // 日志级别
    "LogDirectory": "logs/"     // 日志目录
  }
}
```

### 2. 配置日志设置

编辑 `NLog.config` 文件，根据需要调整日志配置。

### 3. 检查依赖项

确保项目依赖项完整，执行以下命令还原依赖：

```bash
dotnet restore
```

## 故障排除

### 常见问题

#### 1. .NET SDK 未找到

**症状**：脚本显示 ".NET SDK 命令执行失败"

**解决方案**：
- 下载并安装 .NET SDK 8.0 或更高版本
- 访问 https://dotnet.microsoft.com/zh-cn/download

#### 2. 构建失败

**症状**：脚本显示 "构建失败"

**解决方案**：
- 检查项目文件是否正确
- 检查依赖项是否完整
- 运行 `dotnet restore` 还原依赖

#### 3. 发布失败

**症状**：脚本显示 "发布失败"

**解决方案**：
- 检查磁盘空间是否充足
- 检查目录权限是否正确
- 确保目标框架配置正确

#### 4. 可执行文件缺失

**症状**：脚本显示 "未找到可执行文件"

**解决方案**：
- 检查项目输出类型是否为 "Exe"
- 检查目标框架配置
- 重新运行构建和发布命令

### 手动验证

如果脚本执行出现问题，可以手动验证以下内容：

1. **检查 .NET SDK**：`dotnet --version`
2. **检查项目文件**：`dotnet build -c Release --verbosity normal`
3. **检查发布输出**：`dir publish /B`

## 发布后的操作

### 部署到其他机器

1. **复制发布目录**
   - 将整个 `publish/` 目录复制到目标机器

2. **运行应用程序**
   - 双击 `BingSearchAutomation.exe` 启动
   - 或在命令行中运行：`BingSearchAutomation.exe`

### 验证运行

1. **检查日志文件**
   - 应用程序会在 `logs/` 目录生成日志文件
   - 查看日志确认应用程序运行状态

2. **测试功能**
   - 确认搜索功能正常工作
   - 检查配置是否生效
