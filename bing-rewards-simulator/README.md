# BingSearchAutomation

BingSearchAutomation 是一个自动化Bing搜索的工具，可帮助用户自动完成Bing搜索任务，适用于Bing Rewards等场景。

> **程序运行期间请勿使用键盘和鼠标进行任何操作，否则可能导致程序行为异常或搜索任务中断！**

## 项目特点

- 自动化浏览器操作
- 键盘模拟功能
- 可配置的搜索参数
- 详细的日志记录

## 依赖项

- Newtonsoft.Json - JSON处理库
- NLog - 日志记录库
- WindowsInput - 键盘输入模拟库

## 使用方法

1. 确保配置文件 `appsettings.json` 已正确设置
2. 运行可执行文件 `BingSearchAutomation.exe`
3. 程序将自动打开浏览器并执行搜索任务。

> **重要提醒：程序运行期间请勿使用键盘和鼠标进行任何操作，否则可能导致程序行为异常或搜索任务中断！**

## 注意事项

- 本工具仅供学习和个人使用
- 请遵守Bing的使用条款和服务协议
- 过度使用可能会导致账户限制
- 建议合理设置搜索间隔和搜索次数
- **特别注意：运行程序时请勿操作键盘和鼠标，以免干扰自动化流程**

## 故障排除

### 常见问题

1. **浏览器无法打开**：检查浏览器路径配置是否正确
2. **搜索不执行**：检查网络连接和Bing网站可访问性
3. **脚本执行错误**：查看日志文件获取详细错误信息

### 日志查看

日志文件位于 `logs/` 目录，按日期命名（如 `2026-02-02.log`）。您可以通过查看日志文件来诊断问题。
